# A small store, built with care.

We believe the things you bring home for the animals you love should be chosen
the way you'd choose them yourself — deliberately, and without the noise.

So that's what this is. A tight, hand-picked collection instead of an endless
aisle. A few genuinely good things, each one worth its place, each one we'd
happily keep for our own.

No clutter. No filler. Just the good stuff, and a checkout that gets out of the
way.
